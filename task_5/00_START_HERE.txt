    source ../task_2/kubespray/venv/bin/activate
    
    ✓ Если всё правильно, в терминале появится: (venv) user@mac task_5 %

    Откройте GitLab: http://gitlab.test.local
    
    ├─ Логин: root
    ├─ Пароль: посмотреть в ../task_4/DEPLOYMENT_INFO.md
    ├─ Перейти: Admin → CI/CD → Runners
    └─ Нажать: New instance runner
    
    ✓ Скопируйте Registration token (начинается с glrt_)

    export GITLAB_RUNNER_TOKEN="glrt_XXXXXXXXXXXXX"
    
    # Запустите playbook

✨ ПОСЛЕ УСТАНОВКИ:

1. Проверить в GitLab UI:
   http://gitlab.test.local/admin/runners
   
   Должны появиться:
   ✓ k8s-runner-worker1
   ✓ k8s-runner-worker2

2. На worker ноде проверить:
   ssh -i ../task_1/.vagrant/machines/worker1/vmware_fusion/private_key \
       -p 2200 vagrant@127.0.0.1
   
   sudo gitlab-runner status

3. Протестировать runner:
   Создать .gitlab-ci.yml в репозитории и запустить pipeline
